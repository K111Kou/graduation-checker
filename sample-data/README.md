# 卒業要件チェッカー サンプル成績CSV

このフォルダのCSVは、卒業要件チェッカーの動作確認用に作成した架空データです。
R6（2024年度入学）を中心に、代表的な判定パターンを用意しています。
実在する学生・成績とは関係ありません。

## 使い方

1. 卒業要件チェッカーを開きます。
2. 下表の入学年度・コースに合わせて設定します。
3. 対応するCSVを「成績CSV」から選択します。
4. 「判定する」を押して、想定結果と比較します。

## サンプル一覧

| ファイル | 入学年度 | コース | 想定結果 |
|---|---|---|---|
| `01_R6_2024_IS_全要件充足.csv` | 2024 | IS | 卒業要件をすべて満たす想定 |
| `02_R6_2024_IS_必修不足.csv` | 2024 | IS | 必修「卒業研究」不足で未達 |
| `03_R6_2024_IS_専門選択不足.csv` | 2024 | IS | 専門選択を5単位分減らした未達パターン |
| `04_R6_2024_DS_全要件充足.csv` | 2024 | DS | DSの選択必修セットを含め、すべて満たす想定 |
| `05_R6_2024_DS_選択必修不足.csv` | 2024 | DS | 選択必修セットの「社会・観光情報学Ⅲ」不足で未達 |
| `06_R6_2024_IS_不合格と重複を含む.csv` | 2024 | IS | 「情報ネットワークⅠ」がD評価で未取得。重複科目は二重計上されない確認用 |
| `07_参考_R7_2025_DS_全要件充足.csv` | 2025 | DS | R7ルールの参考用・全要件充足 |
| `08_参考_R2_2020_IS_全要件充足.csv` | 2020 | IS | R2の教養40単位ルール・Shift_JIS確認用 |

## 補足

- 01〜06はR6（2024年度入学）の確認用です。
- 07・08は年度差を確認するための参考データです。
- 合格扱いは `AA / A / B / C / 合` です。
- 06ではD評価の必修科目は取得済みに含まれません。
- 同一の専門科目が重複していても、単位を二重計上しないことを確認できます。
- これらは動作確認用データで、NU-Webから出力した実際の `kakuteiseiseki.csv` ではありません。
