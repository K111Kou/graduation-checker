# 卒業要件チェッカー

NU-Webから出力した成績CSVを読み込み、長崎大学情報データ科学部の卒業要件に対する達成状況を確認するWebアプリケーションです。

入学年度・コースごとの履修要件に基づき、必修科目、選択必修科目、選択科目、教養教育科目などの取得状況を判定します。

> [!WARNING]
> 本システムの判定結果は参考用です。  
> 最終的な卒業要件については、大学が公開している履修案内・履修規程等を確認してください。

---

## Features

- NU-Webから出力した成績CSVの読み込み
- 入学年度ごとの卒業要件判定
- IS / DSコースへの対応
- 必修科目の未修得判定
- DSコースの選択必修科目判定
- 専門選択科目の必要単位数判定
- 教養教育科目の区分別単位数判定
- 卒業までに不足している単位数の表示
- 未修得必修科目と標準履修年次の表示
- UTF-8 / Shift_JIS形式のCSV読み込み
- 同一科目の重複取得による二重計上の防止
- ブラウザ内での成績データ処理

## Usage

### 1. ダウンロード

このリポジトリをZIP形式でダウンロードします。

GitHub上部の

`Code` → `Download ZIP`

を選択してください。

ダウンロード後、ZIPファイルを展開します。

### 2. 起動

展開したフォルダ内の

`index.html`

をブラウザで開きます。

特別なソフトウェアや開発環境をインストールする必要はありません。

### 3. 成績CSVの取得

NU-Webにログインします。

1. 「成績」を選択します。
2. 「単位修得状況照会」を開きます。
3. 「過去の成績を含めた全成績」を選択します。
4. 「ファイルに出力する」を選択します。

出力された

`kakuteiseiseki.csv`

を使用します。

### 4. 卒業要件を判定

1. `kakuteiseiseki.csv` を選択します。
2. 入学年度を選択します。
3. コースを選択します。
4. 「判定する」を押します。
5. 卒業要件の達成状況、不足単位、未修得必修科目などを確認します。

- 他年度の卒業要件を使用したケース

サンプルデータはすべて動作確認用の架空データであり、実在する学生の成績ではありません。

## File Description

### `index.html`

アプリケーションのエントリーポイントです。

入学年度・コース・成績CSVを選択するフォームや、判定結果を表示するためのHTML構造を定義しています。

---

### `css/style.css`

画面全体のデザインを定義しています。

主に以下の表示を担当します。

- 入力フォーム
- 判定ボタン
- 卒業要件の進捗表示
- 判定結果
- テーブル
- 不足科目一覧
- レスポンシブ表示

---

### `js/main.js`

アプリケーション全体の制御を担当します。

ユーザーからの入力を受け取り、

1. CSVの読み込み
2. 成績データの解析
3. 卒業要件の判定
4. 判定結果の表示

という一連の処理を各モジュールへ渡します。

`csv.js`、`checker.js`、`ui.js`などをつなぐ役割を持っています。

---

### `js/csv.js`

NU-Webから出力された成績CSVの解析を担当します。

主な処理は以下の通りです。

- CSVファイルの読み込み
- UTF-8 / Shift_JIS形式への対応
- 科目名の取得
- 単位数の取得
- 評語の取得
- 合格科目の抽出

取得した成績データを、卒業要件判定で利用できる形式へ変換します。

---

### `js/checker.js`

卒業要件判定の中心となる処理を実装しています。

主に以下を判定します。

- 必修科目
- 選択必修科目
- 専門選択単位
- 教養教育科目
- 卒業必要総単位
- 未修得必修科目

また、同一科目が複数存在する場合に単位を重複して計上しないよう処理しています。

---

### `js/ui.js`

判定結果を画面に表示する処理を担当します。

主に以下の情報をHTMLへ反映します。

- 卒業要件の達成状況
- 取得単位数
- 不足単位数
- 進捗状況
- 未修得必修科目
- 選択必修の達成状況
- 各区分の必要単位と取得単位

判定処理と画面表示を分離することで、判定ロジックとUIを独立して変更しやすい構成にしています。

---

### `data/requirements.js`

卒業要件の定義データを管理しています。

入学年度・コースごとに、以下の情報を定義しています。

- 卒業必要総単位
- 必修科目
- 標準履修年次
- 専門選択必要単位
- 選択必修条件
- 教養教育科目の必要単位

判定ロジックそのものと卒業要件データを分離することで、年度による履修要件の違いを管理しやすい構成にしています。

---

### `sample-data/`

卒業要件チェッカーの動作確認用CSVを格納しています。

全要件を満たすケースだけでなく、必修不足、選択単位不足、選択必修不足、不合格科目などを含む複数のパターンを用意しています。

これらはすべてテスト用に作成した架空データです。

---

### `source-docs/`

卒業要件データを作成する際に参照した資料を管理しています。

年度ごとの履修要件を確認し、卒業要件データの作成に利用しています。

---

### `tests/`

卒業要件判定が想定した結果になるかを確認するためのテストを格納しています。

主に以下のケースを確認します。

- 全要件を満たす場合
- 必修科目が不足する場合
- 専門選択単位が不足する場合
- DSの選択必修条件を満たさない場合
- 年度ごとに異なる卒業要件を使用する場合

## Architecture

本システムでは、処理を以下の役割に分離しています。

### CSV解析

`csv.js`

NU-Webから出力されたCSVを読み込み、卒業要件の判定に利用できる成績データへ変換します。

### 判定処理

`checker.js`

成績データと卒業要件データを比較し、各卒業要件を満たしているか判定します。

### 卒業要件データ

`requirements.js`

入学年度・コースごとの卒業要件を保持します。

### UI

`ui.js`

判定結果をユーザーが確認できる形で画面へ表示します。

### アプリケーション制御

`main.js`

各処理を連携させ、CSVの読み込みから判定結果の表示までを制御します。

このように、以下の役割を分離することで保守しやすい構成を目指しています。

- CSV解析
- 卒業要件データ
- 判定ロジック
- UI
- アプリケーション制御

## Graduation Requirement Logic

本システムでは、単純に取得単位数だけを比較するのではなく、複数の条件を個別に判定しています。

### 必修科目

必修として指定されている各科目について、取得済みであるかを確認します。

未修得の場合は、科目名と標準履修年次を不足科目として表示します。

### 選択必修科目

DSコースなどで設定されている選択必修科目について、指定された科目の組み合わせを満たしているか確認します。

単純な取得単位数だけではなく、必要な科目セットを満たしているかを判定します。

### 専門選択科目

取得した専門選択科目の単位数を集計し、入学年度・コースごとに設定された必要単位数と比較します。

未修得の選択科目を一つずつ不足科目として扱うのではなく、必要な残り単位数として判定します。

### 教養教育科目

年度ごとに設定された教養教育科目の区分と必要単位数を確認します。

入学年度によって教養教育科目の構成が異なるため、それぞれの年度に対応した条件を使用します。

### 卒業必要総単位

必修、選択必修、専門選択、教養教育科目などの条件に加えて、卒業に必要な総単位数を満たしているか確認します。

## Privacy

成績CSVの解析と卒業要件の判定は、利用者のブラウザ内で実行されます。

成績CSVを外部サーバーへアップロードして判定する仕組みではありません。

そのため、本システムの利用によって成績CSVが開発者のサーバーへ送信されることはありません。
