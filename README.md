# 卒業要件チェッカー v2

## 変更点

この版は、同梱した4つのRTF（R2 / R3・R4・R5 / R6 / R7）を基準に判定モデルを作り直しています。

- R2: 教養40単位、卒業126単位
- R3・R4・R5: 教養30単位、卒業126単位
- R6: 教養30単位、卒業126単位
- R7: 教養31単位、卒業127単位
- 専門必修は、別表第2で「必修」とされた個別科目をすべて確認
- 専門選択は「選択科目を全部取る」のではなく、別表第1の最低修得単位数で確認
- DSの選択必修は、RTF備考にある指定科目セットの「いずれか1組」を確認
- 標準履修年次を未修得必修科目に表示
- 副専攻プログラムは、CSV上で「副専攻」と識別できる科目のみ8単位まで専門選択へ算入
- R7の経済学部相互履修も、CSV上で「相互履修」と識別できる科目のみ8単位まで専門選択へ算入

## 使い方

1. ZIPを展開
2. `index.html` をブラウザで開く
3. 成績CSVを選択
4. 入学年度・IS/DSを選択
5. `判定する`

外部ライブラリは使っていないため、基本機能はオフラインで動きます。

## CSV解析

UTF-8とWindows-31J (Shift_JIS) に対応しています。ヘッダ名から科目名・単位・評価・区分列を探し、見つからない場合は従来の形式（5行ヘッダ、3/5/6/10列目）へフォールバックします。合格扱いは従来コードと同じ `AA / A / B / C / 合` です。

## 注意

教養教育はRTFの「科目区分・最低修得単位数」を基準に判定します。CSV側の区分名が学則表と異なる場合は、`未分類の合格科目` に表示されます。その場合は `data/requirements.js` のカテゴリ別名や `js/checker.js` の表記互換を追加してください。

2021〜2024年度については、従来コードに存在した `プラネタリーヘルスⅠ/Ⅱ科目 → 教養モジュールⅠ/Ⅱ科目` の区分互換を維持しています。

このツールは確認補助用です。最終的な卒業可否は大学の公式な履修・卒業判定を優先してください。
