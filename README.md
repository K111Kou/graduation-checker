# 卒業要件チェッカー

## ダウンロード方法

1. `graduation-checker.zip` をダウンロードします。
2. ダウンロードしたZIPファイルを展開します。
3. 展開したフォルダ内の `index.html` を確認します。

## 成績CSVの入手方法

このシステムでは、NU-Webから出力した成績CSVファイルを使用して判定を行います。

1. NU-Webにログインします。
2. メニューから「成績」を選択します。
3. 「単位修得状況照会」を開きます。
4. 「過去の成績を含めた全成績」を選択します。
5. 「ファイルに出力する」を押します。
6. `kakuteiseiseki.csv` が出力されます。
7. 卒業要件チェッカーの「成績CSV」から、出力した `kakuteiseiseki.csv` を選択してください。

この `kakuteiseiseki.csv` に記録されている修得科目・単位数・成績をもとに、卒業要件の達成状況を判定します。

## 使用方法

1. `index.html` をダブルクリックしてブラウザで開きます。
2. 「成績 CSV」から、自分の成績CSVファイルを選択します。
3. 自分の入学年度を選択します。
4. 自分のコースを選択します。
   - IS：インフォメーションサイエンスコース
   - DS：データサイエンスコース
5. 「判定する」を押します。
6. 卒業要件の達成状況、不足単位、未修得の必修科目などを確認します。

### 注意

- ZIPの中身は削除せず、フォルダ構成をそのまま使用してください。
- 成績CSVはブラウザ内で処理されます。
- 判定結果は参考用です。最終的な卒業要件の確認は、大学が公開している履修案内・要項等でも確認してください。
