# 卒業要件チェッカー

## ダウンロード方法

1. `graduation-checker-v2.zip` をダウンロードします。
2. ダウンロードしたZIPファイルを展開します。
3. 展開したフォルダ内の `index.html` を確認します。

## 使用方法

1. `index.html` をダブルクリックしてブラウザで開きます。
2. 「成績 CSV」から、自分の成績CSVファイルを選択します。
3. 自分の入学年度を選択します。
4. 自分のコースを選択します。
   - IS：インフォメーションサイエンスコース
   - DS：データサイエンスコース
5. 「判定する」を押します。
6. 卒業要件の達成状況、不足単位、未修得の必修科目などを確認します。

### 注意

- ZIPの中身は削除せず、フォルダ構成をそのまま使用してください。
- 成績CSVはブラウザ内で処理されます。
- 判定結果は参考用です。最終的な卒業要件の確認は、大学が公開している履修案内・要項等でも確認してください。
